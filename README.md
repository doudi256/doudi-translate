# Doudi Translate — دودي ترجمة

موقع ترجمة مبني على مشروع بوت Telegram المرفق، مع واجهة ويب متجاوبة.

## المزايا
- اللغات الـ16 الموجودة في ملف البوت.
- اكتشاف لغة النص تلقائياً عبر خدمة الترجمة المستخدمة في البوت.
- ترجمة النصوص إلى اللغة المختارة.
- نسخ النتيجة، لصق النص، ومسح حقل الإدخال.
- سجل آخر 30 ترجمة محفوظ محلياً في متصفح الجهاز.
- واجهة عربية متجاوبة للهاتف والحاسوب.

## التشغيل محلياً
يتطلب Python 3.10 أو أحدث.

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# Linux / macOS:
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

افتح `http://127.0.0.1:5000`.

## النشر
ارفع ملفات المشروع إلى خدمة استضافة تدعم Python/Flask، واجعل أمر التشغيل:
`gunicorn app:app`

ويجب أن تدعم الاستضافة اتصالات HTTPS الصادرة إلى خدمة الترجمة.

## ملاحظات مهمة
- تم نقل منطق الترجمة من البوت كما هو تقريباً: طلب GET إلى `clients4.google.com/translate_a/t` مع `sl=auto` و`tl` للغة الهدف.
- هذا endpoint غير رسمي وقد يتغير أو يضع حدوداً للطلبات؛ لذلك قد تتوقف الترجمة أحياناً. لا توجد هنا ضمانة توفر أو SLA من Google.
- سجل الترجمات محفوظ في `localStorage` على نفس المتصفح والجهاز، وليس في حساب سحابي.
- الموقع مجاني من ناحية الكود؛ الاستضافة والنطاق قد تكون لهما تكلفة حسب المزود.
- لا تضع Bot Token في ملفات الموقع. رمز البوت في الملف المرفق كان قيمة تجريبية `000` ولم نحتج إليه في نسخة الويب.
